# Verification and limits

The original local integration was exercised in Edge at 1440×1000 and 390×844: SearXNG searches returned actual sources in Tools, Research and Knowledge; a generated, nonprivate PDF was uploaded, processed by actual Docling, previewed, exported as Markdown and handed to an unsent assistant draft. Encoded Operations routes survived reload. Health actions showed progress and completed results. All 12 primary sections rendered without horizontal overflow or browser page errors.

The generic release has a separate lockfile install, setup, type check, regression suite and production build. Tests use reserved-domain fixtures; those fixtures do not configure production. Actual Docker services, scanners, cloud credentials and optional studios are separate prerequisites. Unit tests are not evidence that a user's optional programs or provider accounts are installed or working. Windows inventory/Defender/native OCR are Windows-only. Trading remains offline research; no broker execution is implemented or claimed by this UI refactor.

Security boundaries retain loopback Host/Origin checks, same-origin sessions, source content hashes, explicit source application and knowledge approval. No login page is added for the sole local operator. Scoped volunteer pairing and third-party service controls remain.
